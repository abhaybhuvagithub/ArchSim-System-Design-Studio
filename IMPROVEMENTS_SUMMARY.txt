💡 "IMPROVE" & "QUICK FIX" BUTTONS (Key Feature):

Improve Button:
  Current state: Load 1k rps, $2.4k/mo, cache hit 65%
  
  System detects: "You're not optimal"
  Suggests 3 changes (ranked by impact):
    1. "Increase cache TTL" → +20% hits, -$200/mo
    2. "Add read replicas" → -60ms latency, +$800/mo  
    3. "Split services" → easier scaling, +$0/mo
  
  [User picks one] → Design updates → Re-simulates → Next suggestions evolve

Quick Fix Button (For Chaos):
  When chaos injected:
    p99 latency = 8.5s (SLO breach)
    Error rate = 12%
  
  System shows top fixes:
    1. "Add timeout + circuit breaker" → p99 drops to 1.2s ✓
    2. "Route to backup region" → 0 errors during outage
    3. "Queue writes" → guarantee no data loss
  
  [Click fix] → Applies to design → Re-simulates → Shows improvements
