# 5-user test protocol (15 min each)

## Setup
- Their machine, their browser. You say nothing except the task prompts.
- Screen-record with permission. Note every hesitation > 3 seconds.

## Tasks (read aloud, then silence)
1. "Open this link. Figure out what this tool is for." (2 min — do they
   find a template? do they press Simulate unprompted?)
2. "Find out what part of this design fails first under load." (3 min —
   slider? capacity tab? do they discover utilization colors?)
3. "Something is broken in production. Simulate a failure and fix it."
   (3 min — Chaos tab discovery, quick-fix discovery)
4. "Get code you could actually run from this design." (2 min — Code tab)
5. "You have a question about this design. Get an answer inside the tool."
   (2 min — Ask AI vs Explain vs Brief — which do they reach for?)

## Post-task questions (3 min)
- "What did you think this was for, before you clicked anything?"
- "What almost made you close the tab?"
- "What would you use this for next week, if anything?"
- "What felt fake or wrong?"

## Scoring
A task "passes" if completed without help in the time box. Under 4/5 users
passing a task = that flow gets redesigned before any new feature ships.
